Theme properties are supplied at render time. The bundled schema says the Theme API version is injected by the runtime rather than read from `Info.plist`.

The following values are demonstrated by bundled themes. This is not yet a complete object reference.

## content

These values insert content generated by Stacks and other page components:

- `content.prefix` — content before the doctype.
- `content.headAbove` — content near the beginning of `<head>`.
- `content.headBelow` — content near the end of `<head>`.
- `content.bodyAbove` — content before normal page stacks.
- `content.body` — the page's primary Stacks content.
- `content.bodyBelow` — content after normal page stacks.
- `content.suffix` — content after the closing document markup.

Do not omit these casually. Other stacks can publish page-scoped templates into the above/below insertion points.

## page

The Sample theme demonstrates:

- `page.title`
- `page.uid`
- `page.fileName`
- `page.link`

Additional page properties may be present. Rendering `:(page):` during development can help inspect the current runtime object, but debug output should not be shipped in a production theme.

## site

The Sample theme demonstrates:

- `site.baseURL`
- `site.domain`
- `site.title`
- `site.urlString`
- `site.copyright`
- `site.pages.children`
- `site.theme.parent.title`
- `site.theme.parent.uid`

## Navigation pages

Items from `site.pages.children` demonstrate:

- `href`
- `title`
- `navTitle`
- `children`

Nested navigation can be built by iterating over `children` or by passing the page item to an included partial.

## Breadcrumbs

The Sample theme iterates over `breadcrumbs`. Each demonstrated breadcrumb has:

- `current`
- `title`
- `href`

## Theme identity

Base contains debug examples for:

- `theme.title`
- `theme.uid`
- `site.theme.parent.title`
- `site.theme.parent.uid`

The complete relationship between the top-level `theme` object and `site.theme` is not yet specified.

## Output paths

Blank demonstrates:

- `siteCssPath`
- `layoutCssPath`
- `pageCssPath`
- `pageJsPath`

Base also refers to `assetPath` in its comments. Themes with static assets should prefer runtime-generated paths over hard-coded page-relative URLs.

## Inspecting objects safely

Sample suggests temporarily outputting an object during development:

```html
<pre>:(site):</pre>
```

Use this only in a local test theme. Runtime objects may contain verbose implementation details and their unescaped representation may not be appropriate for public output.

## Additional runtime keys

**Binary:** The export context that feeds theme templates resolves the following keys in addition to the ones demonstrated above. Names are exact; the value shapes are inferred from the name and from how the bundled themes use similar keys.

### Theme and layout paths

| Key | Meaning |
|---|---|
| `themePath` | Published folder of the current theme (`:(themePath):/assets/...`). |
| `themeAssetPath` | Published folder for the theme's declared `assets`. |
| `themeCssPath` / `themeJsPath` / `themePhpPath` | The theme's exported `stacks.css`, `stacks.js` and `stacks.php`. |
| `siteThemesPath` | Parent folder that holds every published theme. |
| `layoutPath` | Published folder of the current layout. |
| `layoutCssPath` / `layoutJsPath` / `layoutPhpPath` | The layout's exported CSS, JavaScript and PHP files. |
| `siteCssPath` / `siteJsPath` / `sitePhpPath` | Site-scoped generated files. |
| `pageCssPath` / `pageJsPath` / `pagePhpPath` / `pageAssetPath` | Page-scoped generated files and page assets. |

### Navigation and page metadata

| Key | Meaning |
|---|---|
| `navTitle` | Navigation title of the current page. |
| `navLink` | Link to the current page as used in navigation. |
| `breadcrumbs` (also `breadCrumbs`, `breadcrumb`, `breadCrumb`, `crumb`) | Breadcrumb trail for the current page. The Sample theme iterates `breadcrumbs`. |
| `navigation` | Navigation tree (shape **Unconfirmed**; `site.pages.children` is the demonstrated route). |
| `domain`, `urlString`, `copyright`, `baseURL` | Site settings, also reachable as `site.domain` and so on. |
| `jQueryCompatibility` | The site's jQuery compatibility setting. |

### Export bookkeeping

`exportFileName`, `exportFilePath`, `exportFolderName`, `exportFolderPath`, `assetFolderName`, `siteAssetFolderName` and `sharedExportFolder` describe where the current page is being written. They are implementation details and should not be relied on in a distributed theme.

### Versions

`stackAPIVersion`, `themeAPIVersion`, `stacksVersion`, `stacksBuild` and the `macOS*Version` keys from the Stack API are available. Stacks 6.0 reports Theme API version `60000` and Stack API version `1500`.
