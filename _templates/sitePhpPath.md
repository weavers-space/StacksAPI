### Usage

```html
%sitePhpPath%
```

### Description

The path of the PHP file that Stacks 6 generates once for the whole site. See [`%siteCssPath%`]({% include docs-root.html %}/templates/siteCssPath).

> Introduced in Stacks 6.0 (Stack API version 1500).
