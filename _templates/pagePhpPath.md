### Usage

```html
%pagePhpPath%
```

### Description

The path of the PHP file Stacks generates for the current page. See [`%pageCssPath%`]({% include docs-root.html %}/templates/pageCssPath) for the family of page-, layout- and site-scoped paths.

> Introduced in Stacks 6.0 (Stack API version 1500).
