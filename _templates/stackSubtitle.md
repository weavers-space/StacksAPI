### Usage

```html
%stackSubtitle%
```

### Description

Replaced by the `subtitle` value from the stack's Info.plist, the same way [`%stackTitle%`]({% include docs-root.html %}/templates/stackTitle) returns `title`.

> Introduced in Stacks 6.0 (Stack API version 1500).
