A one-line description shown beneath the stack's [`title`]({% include docs-root.html %}/keys/title) in the Stacks Library. In Stacks 6 it is also available to templates as [`%stackSubtitle%`]({% include docs-root.html %}/templates/stackSubtitle).

```xml
<key>subtitle</key>
<string>A solid base to build on.</string>
```
